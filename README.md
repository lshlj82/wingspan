# 윙스팬 규칙 배우기 (비공식 한국어 인터랙티브 가이드)

보드게임 **윙스팬(Wingspan)** 의 규칙을 한국어로, 직접 눌러 보며 익힐 수 있는 한 페이지짜리 웹 가이드입니다.

## 무엇을 할 수 있나요

- **게임 개요**: 라운드마다 행동 큐브가 8 → 7 → 6 → 5개로 줄어드는 흐름
- **게임 준비**: 새 카드와 먹이를 합쳐 5개만 남기는 선택을 슬라이더로 체험
- **새 카드 읽기**: 예시 카드의 번호를 눌러 서식지, 먹이 비용, 점수, 둥지와 알 한도, 날개 길이, 능력 확인
- **직접 해 보기**: 4라운드 1인 미니 게임. 새 내놓기와 칸별 알 비용, 모이통 주사위, 알 낳기, 카드 뽑기, 갈색 능력의 오른쪽→왼쪽 연쇄 발동
- **되돌리기**: 잘못 누른 조작을 한 단계씩 취소 (라운드를 넘어가거나 “처음부터”를 누른 뒤에도 가능)
- **컴퓨터 시연**: 컴퓨터가 한 판을 두며 각 행동을 고른 이유와 적용되는 규칙을 설명. 멈춤, 한 단계씩 보기, 속도 조절, 중간부터 직접 이어서 하기 지원
- **컴퓨터 대결**: 🦉 점수형과 🐦 엔진형 두 컴퓨터가 한 판을 겨루는 것을 구경. 공유 모이통·진열대 경쟁, 라운드 목표 순위 다툼, 상대 차례에 발동하는 분홍 능력, 흰색 능력을 차례마다 설명하고 게임 끝에 승부가 갈린 이유를 요약
- **새의 능력**: 갈색, 흰색, 분홍색 능력의 발동 시점
- **라운드 종료 정리**와 **최종 점수 계산기**
- 라이트/다크 모드 전환 (선택은 브라우저에 저장)

## 실행 방법

빌드 과정이 없습니다. `index.html`을 브라우저로 열면 바로 동작합니다.

### GitHub Pages로 공개하기

1. 이 저장소의 **Settings → Pages**로 이동합니다.
2. **Source**를 `Deploy from a branch`로, 브랜치를 `main`, 폴더를 `/ (root)`로 지정합니다.
3. 잠시 후 `https://<사용자명>.github.io/<저장소명>/`에서 페이지를 볼 수 있습니다.

## 알려 둘 점

- 미니 게임의 새 카드, 능력, 라운드 목표는 설명을 위해 만든 **예시**이며 실제 게임 카드의 수치와 다릅니다.
- 짝수 칸의 교환 보너스 등 일부 규칙은 데모에서 생략하고 본문에서 설명만 합니다.
- 정확한 규칙은 게임에 포함된 공식 규칙서를 참고하세요.

## 면책

이 프로젝트는 팬이 만든 **비공식** 학습 자료입니다. Stonemaier Games 및 게임 디자이너와 관련이 없으며, 그들의 승인이나 후원을 받지 않았습니다. "Wingspan"과 관련 상표는 각 권리자의 소유입니다. 이 저장소에는 게임의 일러스트, 카드 이미지, 로고, 규칙서 문구가 포함되어 있지 않으며, 규칙은 직접 작성한 문장으로 요약했습니다.
